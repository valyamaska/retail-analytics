# Retail Sales & Customer Behavior Analysis

## О проекте

Проект посвящён анализу продаж интернет-магазина на основе транзакционных данных за 2010–2011 годы. Цель — изучить динамику выручки, покупательское поведение, популярность товаров и географическое распределение продаж.

В ходе работы данные были очищены и подготовлены для анализа, рассчитаны ключевые бизнес-метрики и выявлены особенности структуры продаж.

## Инструменты

## Данные

Используется датасет Online Retail с транзакциями британского интернет-магазина за период с декабря 2010 года по декабрь 2011 года.

Исходный датасет содержит 541 909 строк и 8 столбцов:

- `InvoiceNo` — номер счёта;
- `StockCode` — код товара;
- `Description` — описание товара;
- `Quantity` — количество единиц товара;
- `InvoiceDate` — дата и время операции;
- `UnitPrice` — цена за единицу;
- `CustomerID` — идентификатор покупателя;
- `Country` — страна покупателя.
